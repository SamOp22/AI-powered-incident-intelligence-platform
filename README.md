\# Incident Intelligence Platform



An AI-powered incident management platform built using Java,

Spring Boot, PostgreSQL, and React.



\## Project Status



Phase 1: Incident Service



\## Planned Features



\- User authentication using JWT

\- Role-based authorization

\- Monitored service management

\- Alert ingestion

\- Incident grouping and deduplication

\- Incident investigation assistance using AI

\- Notification processing

\- Redis caching

\- React dashboard



\## Technology Stack



\- Java 21

\- Spring Boot

\- Maven

\- Spring Security

\- Spring Data JPA

\- PostgreSQL

\- Flyway

\- JUnit and Mockito

\- Docker

\- React
